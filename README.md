## Sobre o projeto

O **AGROVANT** é uma landing page de apresentação de um drone agrícola fictício voltado à pulverização e ao monitoramento de lavouras.

O objetivo da página é apresentar o produto, suas funcionalidades, especificações e benefícios, incentivando o agricultor a conhecer melhor a solução e agendar uma demonstração.

Neste projeto, desenvolvi a estrutura da página utilizando HTML e CSS. Também utilizei imagens, vídeos, cards de informações e diferentes seções para apresentar o produto. Uma das partes mais difíceis foi organizar os elementos da página e deixar o site responsivo para funcionar corretamente em diferentes tamanhos de tela.

## Tecnologias utilizadas

* **HTML5** para a estrutura da página
* **CSS3** para estilização
* **Flexbox** para organização dos elementos
* **CSS Grid** para organização dos cards
* **Media Queries** para responsividade
* **HTML semântico** utilizando elementos como `header`, `main`, `section`, `article` e `footer`
* **Imagens** para apresentação visual do produto
* **Vídeos WebM** para demonstração do AGROVANT

## Responsividade

A página foi desenvolvida para funcionar em diferentes tamanhos de tela, proporcionando uma boa experiência tanto em computadores quanto em dispositivos móveis.

| Tela    | Comportamento                                                                                        |
| ------- | ---------------------------------------------------------------------------------------------------- |
| Celular | Os elementos são reorganizados verticalmente e os cards ficam empilhados para facilitar a navegação. |
| Desktop | Os elementos são distribuídos de forma mais ampla, aproveitando melhor o espaço disponível na tela.  |
